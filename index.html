AI Research Engineer

Wipro · Contractual

I turn mathematical and coding problems into benchmarks for large language models. For each task, I define what a correct answer must do, build a reference solution and check how the grader handles edge cases.

When a model misses the mark, I trace the error to a particular step. That helps distinguish a reasoning mistake from an ambiguous instruction or a grading issue.
